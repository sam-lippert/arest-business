# Money

### What a business counts its money in and over. An Amount is a decimal number of the Currency it is stated in; a
### Billing Period is the span a supplier or a business bills over, written as its year and month (2026-02).

## Value Types

Amount is a value type.
  The data type of Amount is decimal.
### An ISO 4217 code, as 'USD'.
Currency is a value type.
  The data type of Currency is text.
Billing Period is a value type.
  The data type of Billing Period is text.

## Domain Metadata

Domain 'money' has Description 'Money and the periods it is counted over: Amount, Currency and Billing Period.'.
